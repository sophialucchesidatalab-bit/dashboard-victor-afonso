# 📊 NOVO CARD: Líquido Total (Realizado + Agendado) ## ✨ O Que Foi Adicionado Um **novo card principal** que mostra o **Líquido Total do mês**, somando: - ✅ Líquido realizado (consultas concluídas) - 📅 Líquido agendado (consultas pendentes) --- ## 🎨 Layout Atualizado ### Antes (5 cards) ``` ┌────────────────────────────────────────────────────┐ │ Líquido │ Previsto │ Bruta │ Repasses │ Ticket │ │ Realizado │ (Velho) │ │ │ Médio │ └────────────────────────────────────────────────────┘ ``` ### Depois (6 cards) - NOVO! ``` ┌──────────────────────────────────────────────────────────────────┐ │ Líquido │ Realizado │ Agendado │ Bruta │ Repasses │ Ticket │ │ Total │ (✅) │ (📅) │ │ │ Médio │ └──────────────────────────────────────────────────────────────────┘ ``` --- ## 💰 O Que Cada Card Mostra ### 1️⃣ **Líquido Total** (NOVO - Verde Escuro) ``` ┌──────────────────────────┐ │ 💰 Líquido Total │ │ │ │ R$ 7.840,00 │ ← Realizado + Agendado │ │ │ Realizado + Agendado │ └──────────────────────────┘ ``` - **Valor:** Soma do líquido realizado + agendado - **Cor:** Verde escuro (principal) - **Icon:** 💰 Moeda ### 2️⃣ **Realizado** (Novo posicionamento - Verde) ``` ┌──────────────────────────┐ │ ✅ Realizado │ │ │ │ R$ 4.830,00 │ │ │ │ 15 consultas concluídas │ └──────────────────────────┘ ``` - **Valor:** Líquido apenas das consultas realizadas - **Subtítulo:** Contagem de consultas concluídas - **Cor:** Verde ### 3️⃣ **Agendado** (Novo posicionamento - Dourado) ``` ┌──────────────────────────┐ │ 📈 Agendado │ │ │ │ R$ 3.010,00 │ ← (Bruto agendado - Repasse estimado) │ │ │ 8 consultas pendentes │ └──────────────────────────┘ ``` - **Valor:** Líquido estimado das consultas agendadas - **Subtítulo:** Contagem de consultas agendadas - **Cálculo:** (Bruto agendado - Repasse estimado) - **Cor:** Dourado (destaque) ### 4️⃣ **Receita Bruta** (Mantido) - Total de receita bruta (realizado + agendado) - Antes dos repasses ### 5️⃣ **Custos / Repasses** (Mantido) - Total de repasses - Percentual da receita bruta ### 6️⃣ **Ticket Médio** (Mantido) - Valor médio por consulta realizada --- ## 🔧 Como Funciona Tecnicamente ### Cálculos Adicionados ```javascript // Dados do realizado const real = records.filter(r => r.status.includes('REALIZADO')); const totLiq = real.reduce((s,r) => s+r.liquido, 0); // ✅ // NOVO: Dados do agendado const agnd = records.filter(r => !r.status.includes('REALIZADO')); const totBrutoAgnd = agnd.reduce((s,r) => s+r.pgto, 0); // Bruto agendado const totRepAgnd = agnd.reduce((s,r) => s+r.repasse, 0); // Repasse agendado const totLiqAgnd = totBrutoAgnd - totRepAgnd; // Líquido agendado // NOVO: Total const totLiqGeral = totLiq + totLiqAgnd; // Realizado + Agendado ``` ### Dados Exibidos ```javascript // Card 1: Líquido Total ${R$(totLiqGeral)} // Realizado + Agendado // Card 2: Realizado ${R$(totLiq)} // Apenas realizado ${real.length} // Contagem // Card 3: Agendado ${R$(totLiqAgnd)} // Apenas agendado ${agnd.length} // Contagem ``` --- ## 📱 Responsividade | Tela | Layout | |------|--------| | **Desktop (>1100px)** | 6 colunas | | **Tablet (768-1100px)** | 3 colunas × 2 linhas | | **Mobile (<720px)** | 2 colunas × 3 linhas | --- ## ✅ Checklist de Verificação -
